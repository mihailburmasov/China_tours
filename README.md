# ChinaTours by Аля

Простая многостраничная веб-страница для продвижения индивидуальных туров по Китаю.

## Что уже сделано
- Главная страница с сильным оффером и CTA
- Страница с маршрутами
- Страница с описанием подхода к поездкам
- Страница контактов с формой заявки
- Адаптивная навигация и современный стиль

## Как открыть
Откройте файл [index.html](index.html) в браузере или запустите локальный сервер из папки проекта.
